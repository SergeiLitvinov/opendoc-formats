# Завершённые вехи выпуска 0.2.0

Принятый объём выпуска завершён. Границы поддержки форматов описаны в руководстве;
ограничение формата не является обещанием будущей реализации.

- [x] M1: аннотации сигнатур внутренних парсеров без изменения их поведения; проверка наличия аннотаций и строгая проверка типов публичного контракта. Динамические границы движков описаны в руководстве.
- [x] M2: проверка читаемости записанных TXT/JSON/HTML/DOCX/PPTX/PDF/LaTeX перед атомарной публикацией; регрессии повреждённых файлов и циклы сложных объектов на собственном корпусе.
- [x] M3: метаданные пакета, единый источник версии, wheel/sdist с ресурсами, изолированная установка и CI Python 3.11/3.12/3.13 + Windows.
- [x] Автоматические API и навигатор, документация okidoki с собственной синей палитрой, поиском и двумя темами.
- [x] GitHub Pages и выпуск по тегу: wheel, sdist и SHA256SUMS.
- [x] Удаление временных файлов из публикации; сохранение лицензионного происхождения.

Новые возможности форматов добавляются по конкретному примеру и приёмке, а не обещанию полной спецификации.
