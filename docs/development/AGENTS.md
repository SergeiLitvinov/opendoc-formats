# Контракт проекта

OpenDoc Formats — самостоятельный пакет обработчиков форматов. OpenDoc подключается без изменений.
Никаких импортов приложения, собственных копий модели, CLI, web или задач.
API импорта находится в opendoc_formats.api, экспорта — в opendoc_formats.export; пути и определения — в docs/reference/code.md.
Обработчики необязательных движков импортируются лениво. Дополнительные поля модели JSON-совместимы.
Новый обработчик возвращает DocumentModel и проходит валидацию OpenDoc; ресурсы открываются только по явной политике.
Команды: uv sync --all-extras, uv run ruff check, uv run pytest, uv run python -m tools.docs generate/check.
Изменение поведения обновляет руководство и историю изменений; generated reference вручную не редактируется.
Публичное API имеет аннотации типов. Внутренние перенесённые парсеры сохраняют поведение до отдельной типизации.
Лимиты/отмена должны честно описывать точку проверки, без обещания прерывания стороннего парсера внутри вызова.
