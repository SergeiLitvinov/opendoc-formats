# Аудит библиотеки

Проверены архитектурные границы, нативное редактирование, импорт/экспорт, ресурсы,
типизация, корпус документов, установка пакетов и автоматизация публикации.

## Самостоятельность

Отдельный пакет со своими версиями и выпусками. **OpenDoc 0.1.0 обязателен**;
полная автономность не заявляется. Единственная обязательная зависимость — официальная
модель OpenDoc. Проверка AST и установленного wheel подтверждает отсутствие импортов
приложения и соседнего дерева исходников. Базовая установка не требует движков форматов.

## Подтверждённые свойства

| Область | Проверка |
| --- | --- |
| DOCX | Реальные split runs, Unicode/табуляции/переносы, колонтитулы, объединения, вложенные таблицы, рисунки/формулы/секции; неизменяемые снимки и исходные ID |
| Транзакции | SHA неизменённых частей, свойства ZIP, точный no-op; конфликт, отмена и лимит сохраняют назначение |
| Безопасный отказ | DTD/entities, повреждённый ZIP, дубликаты, отсутствующие/небезопасные отношения, макросы и подписанные правки |
| PDF | Геометрия и поворот, заранее ограниченные пиксели, bounded cache, effective_scale, ошибки шифрования/индекса/закрытия/отмены |
| Офисный PDF | Реальный LibreOffice и отдельный профиль; timeout/cancel управляемого процесса, проверка PDF до замены |
| Ресурсы | Копия официальной модели, стандартные роли DOCX, отсутствие загрузки URI и выполнения содержимого |
| Импорт/экспорт | Проверка читаемости результата, ресурсы, fallback/provenance через JSON, диагностируемые потери |
| Пакет | Wheel из sdist, базовая/минимальная PDF/полная установка, py.typed, CSS/JS/Lua, отсутствие мусора |
| Документация | Строгая сборка, генерация API и навигатора из AST; адаптивная главная страница, темы и поиск |

## Улучшения относительно предыдущей версии

Версия 0.3.0 добавляет нативные API DOCX/PDF/office и сборку ресурсов.
Исправлены два подтверждённых дефекта PDF: alpha=0 больше не превращается в непрозрачный
цвет; поля на маленьких страницах ограничиваются для валидной модели OpenDoc.
Редактирование полей, охватывающих несколько абзацев, отклоняется до записи.
Список изменений — в [улучшениях версии](changelog.md).

## Воспроизводимая приёмка

`ruff check`, строгий `mypy` публичных модулей, `tools.audit`, полный `pytest`,
`tools.docs check`, `tools.release check`, `twine check` и изолированный
`tools/package_smoke.py` — обязательные проверки CI. Linux: Python 3.11/3.12/3.13;
Windows: 3.12. На Linux 3.12 устанавливается LibreOffice для реального преобразования.
Fixtures описаны в [описании корпуса](corpus.md); нативные проверки — в `tests/native`.
Ссылки навигатора показывают связь с тестами, а не процент покрытия.

## Границы заключения

Корпус не доказывает полной поддержки спецификаций и не заменяет приёмку Office.
Неизменённые части DOCX сохраняются побайтно, но сжатый контейнер может отличаться.
PDF восстанавливает структуру эвристически. Отмена проверяется между вызовами движка;
текст/PNG и выход LibreOffice ограничиваются после его работы, не внутри его памяти.
Профиль LibreOffice не является файловой/сетевой песочницей. OCR и качество preview
определяет потребитель. [Подтверждённая задача](todo.md) и [исследования](research.md)
описывают дальнейшую область развития без обещания полной спецификации.
Лицензии сторонних движков описаны в [уведомлениях](notice.md).
