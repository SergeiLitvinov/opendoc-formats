# Аудит выпуска 0.2.0

Проверены архитектурные границы, контракт импорта/экспорта, ресурсы, типизация,
корпус форматов, установка пакетов, документация и автоматизация выпуска.

## Вывод о самостоятельности

Отдельный пакет со своими релизами. **OpenDoc обязателен** — полная автономность не заявляется.
Проверка AST и запуск установленного wheel в изоляции подтверждают отсутствие прикладных импортов
и зависимости от соседнего дерева исходников. Базовая установка проверяется без extras.

## Приёмка

Исходный корпус: 680 тестов, Python 3.12 / Windows. Добавлены регрессии контрактов,
повреждённого экспорта, отмены при проверке и сетевая граница просмотрщика.
CI выполняет полный корпус на Linux Python 3.11/3.12/3.13 и Windows 3.12.
Релиз проверяет wheel, собранный из sdist, базовую установку без extras, наличие ресурсов
CSS/JS/Lua и `py.typed`, отсутствие временных файлов и соответствие версии тегу.
Ссылки на тесты в навигаторе показывают связь с модулями, а не процент покрытия.

## Границы заключения

Аудит и автоматические тесты не доказывают полную поддержку спецификаций форматов
и не заменяют приёмку редактирования в Word/PowerPoint. PDF восстанавливает структуру эвристически;
EPUB/DjVu-экспорт и произвольный TeX-импорт отсутствуют. Отмена и лимиты проверяются на
описанных границах, без прерывания стороннего парсера. OCR и внешние программы — выбор потребителя.
Лицензионные сведения сохранены в NOTICE; MIT проекта не распространяется на сторонние движки.
