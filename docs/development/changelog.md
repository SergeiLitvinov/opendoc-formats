# История изменений

## 0.2.0 — 2026-10-04

Первый публичный выпуск отдельного пакета OpenDoc Formats в экосистеме okidoki.

- Импорт TXT, HTML/CSS, DOCX, EPUB, PDF, PPTX, JSON OpenDoc и текста DjVu.
- Экспорт TXT, HTML, DOCX, PDF, PPTX, JSON и LaTeX с явной диагностикой потерь.
- Реестры расширений, ленивые движки, лимиты и отмена на границах операций.
- Проверки читаемости результата перед атомарной публикацией; прежний файл сохраняется при ошибке.
- Внедряемый OCR, шрифты/OOXML, PDF → DOCX и PPTX → HTML без автоматической загрузки MathJax из сети.
- Аннотации парсеров, типизированный публичный API и маркер `py.typed`.
- Генерируемая документация в стиле okidoki; собственная палитра и GitHub Pages.
- CI на Python 3.11–3.13 и Windows, проверка wheel/sdist и выпуск по тегу.

Обязательная зависимость: OpenDoc 0.1.0. Библиотека не является автономной от модели OpenDoc.
EPUB/DjVu-экспорт, произвольный TeX-импорт, встроенный OCR и полная визуальная эквивалентность не заявляются.
