# Выпуски

## 0.1.0 — возможности библиотеки

- Самостоятельный пакет `opendoc-formats` с моделью `opendoc-model`, типизированным
  API, JSON, ресурсами, provenance и диагностикой преобразований.
- Импорт и экспорт DOCX, PPTX, PDF, HTML и EPUB в описанных профилях; нативный
  LaTeX source profile, TXT/JSON и отдельный текстовый DjVu-маршрут.
- Нативные снимки и адресные правки DOCX/PDF/PPTX, непрозрачное сохранение
  исходных частей пакетов и ограниченные source-export bindings.
- Собственная бинарная инспекция ZIP/OPC, EPUB, PDF xref/ObjStm, CFBF/OLE,
  шрифтов и PNG с квотами, отменой и точными адресами исходных данных.
- PDF → OpenDoc → DOCX flow-профиль, таблицы и source-grid bindings;
  отдельный legacy converter до завершения сравнительной приёмки.
- Необязательные движки подключаются по extras. Базовому пакету нужен только
  OpenDoc Model; EPUB writer и бинарная инспекция не требуют движков форматов.
- CI для Python 3.11–3.13 и Windows/Linux, изолированная проверка дистрибутивов,
  GitHub Pages, wheel/sdist и контрольные суммы выпусков.
