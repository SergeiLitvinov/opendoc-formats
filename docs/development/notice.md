# Происхождение

Проект распространяется по [лицензии MIT](LICENSE).

Часть обработчиков основана на коде TextAlchemy под лицензией MIT.
Упоминание исходного проекта здесь сохраняет атрибуцию кода и не обозначает runtime-зависимость.
OpenDoc используется без изменений из официального выпуска v0.1.0 как обязательная библиотека модели.

Тема документации адаптирована из OpenDoc (MIT): навигация, поиск, светлая/тёмная темы;
палитра, символика и содержание соответствуют OpenDoc Formats.

Лицензия этого проекта не меняет лицензий необязательных движков. В частности, PyMuPDF
распространяется на условиях [AGPL/commercial](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright);
выбор и распространение PDF-движка нужно учитывать отдельно.
