# Происхождение

Проект распространяется по [лицензии MIT](LICENSE).

Правообладатель собственного кода — Sergei Litvinov. Автор подтвердил права на
перенесённые обработчики. Приложения не являются зависимостями этой библиотеки.
OpenDoc Model используется без изменений из официального выпуска v0.3.0 как обязательная библиотека модели.

Тема документации адаптирована из OpenDoc (MIT, Copyright © 2026 Сергей Литвинов): навигация, поиск, светлая/тёмная темы;
палитра, символика и содержание соответствуют OpenDoc Formats.

Лицензия собственного кода не меняет лицензий зависимостей. **Весь набор extras
не является набором только MIT-компонентов:** PyMuPDF — AGPL/commercial,
EbookLib — AGPL-3.0-or-later; MIT-обёртка pdf2docx зависит от PyMuPDF.
Состав, назначение, первичные источники и условия распространения описаны в
[лицензионном аудите](licenses.md) и [руководстве по зависимостям](../guide/dependencies.md).

Лицензионные уведомления зависимостей сохраняются в их дистрибутивах. Python-wheel
библиотеки не включает код этих движков. Поиск опубликованной документации включает
сторонние JavaScript-компоненты MkDocs; их условия также перечислены в аудите.

AGPL-профили предусмотрены для совместимых открытых проектов. Неподтверждённое
разрешение на два ресурса lxml рассмотрено отдельно в [статусе XSL](lxml-xslt.md);
copyleft и отсутствие лицензионного разрешения являются разными вопросами.
