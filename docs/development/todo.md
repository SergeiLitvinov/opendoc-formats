# Открытые задачи

Здесь перечислена только работа, которую ещё требуется реализовать или принять.
Текущее покрытие — в [разделах по форматам](../guide/format-audit.md),
проверки — в [описании корпуса](corpus.md), границы API — в
[реестре контрактов](format-requests.md#конечные-контракты).

Приоритет: C-PDF-01 и C-MAP-01, затем оставшиеся требования C-DOCX-01/02.
Каждая задача принадлежит OpenDoc Formats. Пробелы общего API согласовывать
[явным контрактом с OpenDoc](opendoc-proposals.md); парсеры, движки, измерения
и нативную приёмку оставлять в Formats.

## Приоритет P0: диагностика импорта (OF15)

- Обеспечить feature/location/severity и состояние semantic/opaque/visual/lost/rejected
  для каждого непереносимого объекта во всех читателях, включая EPUB и PDF.
  Для DOCX связать полный физический инвентарь `.rels` с богатой диагностикой,
  за пределами сохранённой физической dependency closure; раскрыть сохранение остальных известных
  типов вне принятых Custom XML/altChunk/chart/SmartArt/OLE/comment профилей,
  а не считать каталог типов оценкой. Для Custom XML принять общую семантику
  data binding и обновление bound text отдельно от opaque replay данных и `w:dataBinding`.
- Дополнить инвентарь оставшихся прямых legacy-читателей без богатой промежуточной модели
  непереносимыми объектами исходного файла. Для integration scenes/graphs/ranges
  раскрыть агрегатные оценки полей в оценки каждого исходного объекта и его связей.
  Границы текущей оценки — в [ресурсах](../guide/resources.md).
- C-MAP-01: автоматически подтверждать связи произвольных intermediate snapshots,
  полный инвентарь объектов и нативные сценарии произвольного split/merge.
- Для EPUB расширить цели ссылок за пределы профиля статических SVG-фигур
  и локальных градиентов, в том числе для внешних SVG.
- Приёмка: по fixture каждого непереносимого объекта issue указывает источник;
  JSON сохраняет provenance/расширения; отсутствие warnings не выдаётся за lossless.
  Различать отсутствующий backend, отмену и превышение лимитов.

## Общие лимиты и отмена (C-LIMIT-01, P1)

- Ограничить работу, память и ресурсы внутри каждого парсера и всех преобразований;
  бюджет структуры Model не считать бюджетом стороннего декодера.
- Добавить контрольные точки отмены в ещё не охваченные нативные маршруты
  и преобразования; определить прерываемые границы длительных сторонних
  вызовов там, где это допускает API движка.
- Приёмка: входной размер, nodes/depth/bytes/embedded bytes, работа внутри декодера,
  поздний отказ и отмена сохраняют исходник и назначение; квота и адрес ошибки явные.

## Приоритет P1: совместимость зависимостей и версии

- Принять минимальные поддержанные версии каждого runtime extra на матрице
  Python/OS в отдельных средах; по результатам уточнить нижние границы
  `pyproject.toml`. Зелёный frozen CI не считать проверкой всех версий из `>=`.
- Для каждого предлагаемого downgrade сначала воспроизвести причину и сравнить
  API, транзитивный состав, лицензии и требования безопасности; повторить
  installed-profile и нативный corpus gate без изменения исходников/назначения.
- Удалять PDF-движки только после профильных gates OF17, fontTools — после
  равноценной приёмки оставшегося subsetting/fallback, lxml — после приёмки
  альтернативы для всего используемого OOXML/XML профиля и решения OF16.
  Удаление дублирующего требования из manifest не считать удалением зависимости.

- Для нативного DOCX расширить URI-привязки за конечный strict UTF-8 percent-профиль:
  остальные escaped spelling/reserved/dot profiles, relationship-owner aliases,
  fragment/query и согласование полной URI-политики с Anatomy/rich reader.
- В общем инспекторе Anatomy расширить валидацию полей деклараций,
  XML Schema whitespace/IRI/IP-literal профилей Id/Type, полной URI-нормализации
  и неподтверждённых OPC-профилей за пределами конечного физического
  аудита. Принять эти профили на независимых originals с явными отказами/диагностикой.
- Расширить EPUB inspection за пределы строгого локального UTF-8/percent-профиля:
  принять неподтверждённые `xml:base`/query/encoded-separator случаи, полную
  URL-нормализацию и проверку внешних URL,
  неподтверждённые rendition/URI профили и полную диагностику повреждённого
  manifest; сохранять явные отказы и XML policy вне поддержанного профиля.
- Связать сохранённый физический PPTX-инвентарь с редактируемыми объектами
  и адресами экспорта; подтвердить неизвестные компоненты и их зависимости
  независимыми оригиналами и нативной приёмкой. Расширить сопоставление
  физического ZIP-инвентаря на остальные пакетные форматы.
- Для исследуемых функций связать исходные локаторы Anatomy с объектами Model,
  сохранёнными payload и адресами экспорта. Отчёт должен различать доказанную связь,
  неоднозначность и отсутствие покрытия; принять адресную правку с проверкой
  неизменённых соседних объектов по [порядку препарирования](../guide/document-anatomy.md).
  Этот конечный профиль не считать полной автоматической приёмкой C-MAP-01.
- Расширить CFBF inspection за пределы проверенных указателей, цветов, порядка имён
  и directory fields: неподтверждённые требования к именам (включая пустые),
  остальные header/DIFAT-профили и неподтверждённые повреждения. Расширить вложенный ZIP/CFBF обход на
  внутренние application-specific Package wrappers NativeData, остальные контейнеры и semantic bindings;
  принять их отдельно от физического профиля с общим бюджетом глубины/размера.
  Расширить sfnt table inventory на WOFF/WOFF2 и collection-wide TTC/OTC аудит:
  автоматический совокупный обход всех faces в Anatomy, DSIG, межface sharing/overlaps,
  неизвестные диапазоны коллекции и профили за пределами конечных directory/padding/checksum аудитов;
  добавить полную интерпретацию внутренних таблиц, включая variable
  interpolation/instance selection и post/maxp за пределами принятого base-face профиля, оставшиеся
  name/language-tag/encoding профили (включая Macintosh CJK extension bytes за
  пределами стандартных кодеков Python) и cmap за пределами конечного Unicode 0/2/4/6/12/13
  coverage (остальные выбранные форматы, variation sequences, shaping и glyph
  program validation). Расширить GSUB за конечный static TrueType/post-1/2/3/4 профиль
  с ligature lookup 4/7 и структурно проверенными соседними SingleSubst 1/7,
  MultipleSubst 2/7, AlternateSubst 3/7, Context/ChainedContext 5/6/7 formats 1/2/3
  и ReverseChainSingleSubst 8/7
  на другие post profiles,
  flags, неизвестные ClassDef/context profiles и изменение длины input sequence
  за пределами принятого структурного профиля, CFF/variations с прежней политикой неизвестности;
  полный shaping не считать реализованным по наличию Unicode ligature mapping;
  подключить вложенный разбор к Anatomy
  с общим бюджетом. Для PNG реализовать остальные ancillary/color/APNG semantics,
  ICC/cICP/profile precedence, ограниченный pixel decode и исходные image bindings
  за пределами конечных CRC/IHDR/core-order и tRNS/gAMA/sRGB/pHYs declarations.
  Разбирать остальные форматы шрифтов и медиа с контролем смещений, размеров
  и неизвестных полей; не исполнять объекты.
- Для PDF расширить исходную xref-инспекцию на непринятые фильтры и параметры
  за пределами Flate/LZW/RunLength/ASCII-профиля. Для PDF 1.x проверить косвенную
  длину xref-потоков вне профиля собственной классической таблицы;
  параметры ObjStm — на неподтверждённые допустимые случаи за пределами принятого
  профиля несжатых целых объектов, имён фильтров и косвенных словарей
  и массивов с прямыми параметрами. Проверить косвенный массив фильтров
  и допустимые ссылки внутри косвенных словарей. Не допускать запрещённый compressed Length ObjStm.
  Расширить остальные filter/parameter профили. Расширить Extends за конечное сопоставление
  деклараций коллекции и текущей проекции compressed roots: контекстно различающиеся
  indirect parameters, неподтверждённые targets/contexts и полную принадлежность
  объектов/разрешение bodies. Расширить привязку type-2
  за конечное declared-xref сопоставление: неоднозначные hybrid contexts, неподтверждённые
  профили контейнеров и полное разрешение унаследованных ссылок после правок контейнера
  за пределами принятой текущей declared-xref проекции.
  Декодировать отдельные представления контейнера для исторических ревизий
  с различающимися значениями параметров.
  Подтвердить границы
  и принадлежность объектов, разрешение bodies по выбранным xref-записям с проверкой
  reference generations и классификацию incremental
  revisions отдельно от linearized/hybrid ссылок на независимом корпусе.
  Для ссылок внутри ObjStm расширить сопоставление xref declarations на проверку
  полной принадлежности диапазонов за пределами аудита пересечений с уже
  исследованными областями, с учётом проверенных заголовков, обычных тел,
  границ потоков с прямой и косвенной целочисленной длиной, а также номера
  и индекса сжатых целей;
  неподтверждённые source contexts не считать разрешёнными по совпадению объявления.
  Не считать буквальный object header или запись type 2 доказательством разрешённого
  объекта; ремонт backend отделять от исходной структуры.
- Принимать правки относительно независимых оригиналов по нативным структурам,

  на основные функции каждого формата. Буквальное совпадение адреса не считать
  доказательством semantic correspondence или полного C-MAP-01.

  не исполнять TeX, shell escape или сетевые include.
- Приёмка: собственный .tex с .bib и изображением → OpenDoc → JSON → TeX;

  для циклов, неизвестных пакетов и лимитов. Полноту произвольного программируемого
  TeX не объявлять без соответствующего покрытия.

- Для границ таблиц вычислять inherited/conditional styles и конфликты соседних

- Приёмка: DOCX → JSON → DOCX сохраняет IDs/диапазоны и неизменённые части;
  сравнить полные страницы с оригиналом и выполнить нативные правки.
