# Подтверждённые задачи

## Следующая веха: экспорт PDF-вектора (OF03)

**Воспроизводимый пробел:** `read_document` получает из PDF ресурс
`application/pdf+vector` с командами рисования, но `write_document(..., '*.pdf')`
передаёт его в растровый путь и возвращает ошибку. JSON сохраняет команды.
Открытая задача относится к универсальному экспорту библиотеки.

- Fixture: `tests/corpus/native/vector-export.pdf` — прямоугольник с заливкой и обводкой.
- Регрессия: `tests/native/test_format_audit.py`, тест фиксирует текущую ошибку.
- Предпочтительный результат: воспроизведение поддержанных команд в PDF с сохранением
  размера, цвета и прозрачности, без подмены вектора пустым изображением.
- Если команда неподдержана: ограниченный raster fallback с VisualSurrogate/Provenance
  и явной диагностикой потери редактируемости; никакого молчаливого исчезновения.
- Приёмка: читаемый результат, совпадение визуальной геометрии на fixture, корректный
  отчёт потерь, сохранение JSON, ограничения числа команд/выхода и отмена до публикации.
- Неподдержанные команды должны иметь отдельную fixture и диагностику.

Других подтверждённых незакрытых обещаний выпуска 0.3.0 нет.
Непроверенные направления находятся в [исследованиях](research.md).
