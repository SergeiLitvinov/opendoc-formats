# Проверенные возможности форматов

Импорт/экспорт сообщает потери через отчёты; успех не означает полное сохранение
всей спецификации формата. Следующие возможности подтверждены корпусом тестов.

| Область | Подтверждение и граница |
| --- | --- |
| DOCX | Нативные снимки и правки сохраняют соседние runs, изображения, формулы, колонтитулы и неизменённые части; сложная полная замена отклоняется |
| SVG в DOCX | VisualSurrogate и Provenance сохраняются через JSON и повторный DOCX; исходный SVG и растровое представление различимы |
| PDF | Текст, геометрия и ограниченный рендер; нулевая прозрачность сохраняется; маленькие страницы дают валидные настройки OpenDoc |
| PDF-векторы | Импорт извлекает команды рисования; повторный PDF-экспорт ресурса `application/pdf+vector` пока возвращает ошибку, см. конечную задачу |
| PPTX | Корпус проверяет таблицы, диаграммы, текст, группы и OOXML package; это не гарантия всех эффектов и анимаций |
| HTML/CSS | Проверяется статический разбор и заявленные CSS-свойства; произвольный браузерный layout не воспроизводится |
| Цвет | RGB/CMYK, нулевая alpha и диагностика unsupported conversion; полноценное ICC-управление цветом не заявлено |
| DjVu | Внешнее извлечение текста; модель координат и рендер страниц не заявлены |
| XLSX/ODS | Внешнее офисное преобразование в PDF; семантический импорт таблиц в OpenDoc отсутствует |

Фикстуры и происхождение: [описании корпуса](../development/corpus.md); регрессии:
`tests/native/test_format_audit.py`. Более широкие пожелания требуют отдельного
воспроизводимого примера: [исследования](../development/research.md).
